# VLC's skins in RVP

Generated by `cargo test -p rvp-app --test coverage` (`RVP_BLESS=1`) from RVP's VLC builder (`crates/skin/src/vlc/build.rs`) and `crates/app/src/vlc.rs`: VLC 3's skin actions, variables, text codes and slider values, what RVP makes of each, and how RVP draws a theme's parts. RVP builds a skin of its own from a `.vlt` theme (goal K, `docs/spikes/s6-other-skins.md`); no theme is needed to write this report.

49 of VLC's 53 actions run in RVP; 4 do nothing, and their controls show as VLC shows them. A control whose action VLC does not know is left out, as VLC leaves it out; of a `;` list RVP runs the first action it can.

## Text codes

| VLC | RVP |
|-----|-----|
| `$T` | the time, `H:MM:SS` (`-:--:--` without a position) |
| `$t` | the time, `MM:SS` below an hour |
| `$L` | the time left, `H:MM:SS` |
| `$l` | the time left, `MM:SS` below an hour |
| `$D` | the duration, `H:MM:SS` |
| `$d` | the duration, `MM:SS` below an hour |
| `$V` | the volume in RVP's percent (VLC's run from 0 to 200) |
| `$N` | the title (mpv's `media-title`; VLC's follows its title format) |
| `$F` | the file's path |
| `$B` | the audio bit rate in kb/s |
| `$S` | the sample rate in kHz |
| `$R` | the speed |
| `$H` | nothing: RVP keeps no help texts (VLC: the help of the control under the pointer) |

## Slider values

| VLC | RVP |
|-----|-----|
| `time` | the position (`CMD_TIMEBAR_CTRL`) |
| `volume` | RVP's volume over its range (`CMD_VOLUME_CTRL`) |
| `equalizer.band(N)` | band N + 1 of RVP's ten-band equalizer (`CMD_EQULIZER_N`) |
| `equalizer.preamp` | nothing: RVP's equalizer has no preamp (RVP's Preamp raises AC3 and DTS sources only), so the slider stays in the middle |
| `playtree.slider` | left out: RVP's playlist scrolls itself and draws its own scroll bar |

## A theme's parts

| VLC | RVP |
|-----|-----|
| `theme.xml`, `Bitmap`, `SubBitmap`, `Font` | read from the `.vlt` (gzip'd tar or zip); `alphacolor` made transparent, the theme's fonts registered for the process |
| `Window`, `Layout` | the window with the video (else the first shown) is RVP's main window and its layouts files of the built skin; the others are windows of their own in their last layout |
| `Window` `x`, `y` | the other windows keep their place beside the main window and move with it |
| `Anchor` | not read: windows neither snap to each other nor to the screen's edges, they move as one group |
| `Group`, `Panel` | placed as VLC places them, with their corners and kept ratios |
| `lefttop`, `rightbottom`, `xkeepratio`, `ykeepratio` | a control's corners follow its box's as the window resizes; a kept ratio near the middle centres it |
| `Image` `resize` | `mosaic` tiles, `scale` stretches, `scale2` fits keeping the picture's aspect |
| `Image` `action` | `move` drags the window, `resizeE`, `resizeS`, `resizeSE` resize it |
| `Image` `action2` | a double click on a title-bar picture runs it (RVP's title bars maximize otherwise) |
| `Image` `art` | drawn as the picture: no cover art |
| `Button`, `Checkbox` | up, over and down pictures; they take the pointer where their pictures are opaque, as VLC's do |
| animated bitmaps (`nbframes`) | their first frame: RVP's skin pictures do not move |
| `Text` | the theme's font, colour and alignment; a text wider than its box is cut where VLC scrolls it |
| `Text` `focus` | ignored: RVP's labels do not take the pointer |
| `Slider` | the straight track from its first point to its last (a curve, PsVLC's, becomes that line), with its background pictures |
| `RadialSlider` | left out (no theme of the sample has one) |
| `Playtree`, `Playlist` | RVP's playlist in the theme's colours and background; no tree, folder pictures or second row colour |
| `Video` | the video's place; `autoresize` is not read (RVP's Fit window to video setting applies as with any skin) |
| `fullscreenController` | left out: in fullscreen RVP shows the video alone (mpv's on-screen controller can give it controls) |
| `PopupMenu`, `MenuItem` | left out: RVP's own menus |
| tooltips | the theme's, with their text codes filled in |
| transparent pixels | the windows take their shapes from the pictures' opaque pixels |
