# PotPlayer's command line in RVP

Generated by `cargo test -p rvp-app --test coverage` (`RVP_BLESS=1` rewrites it) from R2's `docs/r1/command-line.tsv` (`crates/app/src/instance.rs` reads them).

29 switches: 26 in RVP, 3 not.

| Switch | RVP |
|--------|-----|
| `"content"` | files, folders and URLs open in the shown album (When Files Opened applies); wildcards and URL titles after a backslash are not read |
| `-` | standard input plays (mpv's `-`) |
| `/filedlg` | the Open File(s) dialog |
| `/urldlg` | the Open URL dialog |
| `/folderdlg` | the Open Folder dialog |
| `/simple` | not: PotPlayer's file navigator is not in RVP (docs/spikes/m11-studies.md) |
| `/cap` | the screen capture |
| `/cam` | the webcam or device (the device setting, or a list) |
| `/atv[:ch]` | not: TV tuners are a non-goal |
| `/dtv[:ch[-idx]]` | not: TV tuners are a non-goal |
| `/dvd` | the DVD (the device setting, or the disc dialog) |
| `/cd[:drive]` | the audio CD (cdda://) of the drive |
| `/add` | appends to the shown album |
| `/insert` | inserts below the entry that plays |
| `/autoplay` | the last played item plays |
| `/same` | the files after the first are its streams (external files) |
| `/sort` | the files sort by name first |
| `/randomize` | the files are shuffled first |
| `/new` | another RVP plays them |
| `/current` | the running RVP plays them |
| `/clipboard` | the clipboard's files and URLs open |
| `/seek=time` | the first file starts there (mpv's start) |
| `/sub="subfile"` | the first file's subtitle (mpv's sub-files) |
| `/aud="audiofile"` | the first file's audio (mpv's audio-files) |
| `/user_agent="ua"` | the first file's user agent |
| `/referer="ref"` | the first file's referer |
| `/headers="hdrs"` | the first file's HTTP header fields |
| `/title="title"` | the first file's title (mpv's force-media-title) |
| `config="name"` | starts with that settings preset (Configuration) |
