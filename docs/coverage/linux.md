# RVP on Linux

Generated by `cargo test -p rvp-app --test coverage` (`RVP_BLESS=1` rewrites it) from `crates/app/src/coverage/linux.rs`: the parts whose Linux side differs from Windows', and how Linux does them or why it cannot. Everything else works on Linux as on Windows: it is libmpv's, FFmpeg's, Qt's or RVP's own code.

38 items: 20 the same through Linux's means, 11 in part, 7 not.
