# M2 checks on Windows (goal E)

Dates: 2026-10-10 and 2026-10-11. The `rvp` bundle was cross-built from
WSL (`cargo xwin`, Qt 6.10.3 msvc2022_64, libmpv from shinchiro's
`mpv-dev-x86_64-20261010-git-b2c255c13e`) and assembled with
`spikes/tools/deploy-windows.py`. RVP's settings and state were kept in the
test folders (`RVP_CONFIG_DIR`, `RVP_STATE_DIR`). Every clip is synthetic:
the repository fixtures (96x72, 10 fps) on the VM, and on the host the clips
from goal C (`video-2160p60-hevc.mkv`, 30 s, and `video-1080p23976-h264.mkv`,
60 s, made by `tools/test-clips/make-clips.sh`).

## Windows test VM (`<windows-vm>`, session 0)

Windows 11 VM over SSH: windows are never exposed, so the self-test renders
by grabbing the window and Qt uses software OpenGL (`QT_OPENGL=software`,
Mesa llvmpipe). Audio output `null`.

| Run | Result |
|-----|--------|
| `rvp --selftest` (two fixtures) | PASS: playing, seek, Space pauses and resumes, wheel volume, M mute, PgDn/PgUp next and previous, Enter fullscreen, double click leaves fullscreen, resize to 900x500 relays out, seek bar to the middle, playlist toggle, menu/dialog/tooltip load on demand, a dropped file is appended |
| `--selftest=playback --play-seconds=6`, then a restart with no file | PASS: reopened paused at 9.2 s, where it stopped |

Timings in session 0 measure the VM's software rendering, not RVP, and
are not reported as usability results.

## Windows host (the owner's desktop)

2560x1440 at 59.951 Hz, RTX 30-series card, 100 % scaling. Four runs, each
announced in advance and run only after the owner's explicit permission;
one RVP window at a time, no keyboard or mouse input injected. PotPlayer was
open and idle (its CPU time did not change) and was not touched. Hardware
decoding: `d3d11va-copy`; audio: WASAPI.
